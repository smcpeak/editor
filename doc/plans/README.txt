This directory has "plans", documents written to aid in making some
substantial change, which may or may not have ultimately been made, or
made in the way planned.  The plans are updated as the planning work
progresses, but at some point (e.g., when the work is finished) become
frozen, and are not maintained thereafter, just being part of the
historical record.

Each plan document should have a date indicating when it was made,
giving an indication of its likely pertinence period.

This non-indefinite-maintenance policy is in contrast to doc/, which
*is* supposed to be kept up to date as the code changes (although
whether that actually happens in all cases is another matter).
